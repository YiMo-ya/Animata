# Animata

## (English)

**Animata** is a lightweight 2D animation software that breaks away from traditional "keyframes" by using event-driven animation. It is designed for small animation projects, music video animations, and character meme animations.

## ✨ Features

- 🎬 **Event-Driven Animation** — No more tedious keyframe tweaking; trigger animations through events and logic.
- ⚡ **Lightweight & Fast** — Minimal resource usage, smooth performance even on low-end devices.
- 🎨 **2D Focused** — Purpose-built for 2D content creators, illustrators, and meme makers.
- 🎵 **Music Video Ready** — Perfect for syncing animations to audio and creating song MV visuals.
- 😎 **Meme-Friendly** — Quickly bring characters to life for social media and meme content.
- 🧩 **Simple Workflow** — Intuitive interface designed to get you animating in minutes.

## 💬 About

Animata reimagines 2D animation by replacing traditional keyframes with an event-driven approach — making animation faster, lighter, and more intuitive for creators of all levels.

## (Chinese)

**Animata** 是一款轻量级 2D 动画制作软件，它打破传统的"关键帧"模式，采用事件驱动动画机制。专为小型动画项目、歌曲 MV 和角色 Meme 动画而生。

## ✨ 功能特性

- 🎬 **事件驱动动画** — 告别繁琐的关键帧调整，通过事件和逻辑触发动画。
- ⚡ **轻量高效** — 极低的资源占用，即使在低端设备上也能流畅运行。
- 🎨 **专注 2D** — 专为 2D 内容创作者、插画师和 Meme 制作者打造。
- 🎵 **MV 动画利器** — 完美适配音频同步，轻松制作歌曲 MV 视觉效果。
